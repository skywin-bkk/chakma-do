PUBLICATION CONTROL

A service must pass the exposure gate before it appears here.

1. Evidence

A service or form must have authoritative repository or deployment evidence.

2. Classification

Its public status must be explicit. A public candidate is not the same as website-exposed.

3. Verification

The destination, purpose and public access route must be verified before publication.

4. Registry

Only then may the approved public record be added to the shared services dataset and rendered here.

PROTECTED OPERATIONS

Useful public access without exposing protected systems.

Person and household records, safeguarding information, health information, case management, staff workflows, internal forms, response destinations and restricted operational systems stay outside this public website.
